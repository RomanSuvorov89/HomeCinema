# Работа с HomeCinema

Основной репозиторий всех доработок домашнего кинотеатра: https://github.com/RomanSuvorov89/HomeCinema.

Перед изменениями читать README.md, TODO.md, docs/CONTEXT.md и docs/KNOWN_ISSUES.md. Пользователь разрешил сохранять работы в этом репозитории, при необходимости в отдельных ветках. Завершённые изменения коммитить и отправлять в Git; в ответе давать ссылку на коммит/PR и результат проверок. Не утверждать, что код опубликован, пока отправка не подтверждена.

Цель: воспроизводимая установка после переезда. Не оставлять исправления только на работающем сервере: обновлять исходники, шаблоны, установку и документацию вместе. Адреса, профили и токены брать из конфигурации. Не коммитить базы, пароли, личную историю, резервные копии и реальные конфиги.

Пользователь работает с Windows через SSH в CachyOS, оболочка fish. Даваемые команды должны работать в fish либо явно вызывать bash/PowerShell. Перезапуск Lampac и пересоздание контейнера — разные действия; не менять существующий Portainer stack без необходимости. При изменении смонтированного lampainit.js сохранять inode и делать резервную копию.

Проверки: bash scripts/check.sh. Дополнительные проверки по смыслу изменения. Честно разделять автоматические проверки, проверку пользователем и неподтверждённые сценарии чистой установки/конкретного устройства.
