# История

## Исправление расписания — 2026-10-20

Кинопоиск может перечислять новый сезон только с годом выхода. Раньше такие серии пропускались без предупреждения, и оценённый сериал не попадал в ряд новых серий. Добавлено обнаружение неполного расписания и резервный источник TVmaze с проверкой идентичности, включая отсутствие IMDb ID. Прежние даты сохраняются при ошибке, старый кэш повторно проверяется после обновления парсера. Реальные запросы с домашнего сервера требуют проверки после установки.

## 0.3.0-preview — 2026-10-20

Первый общий исходный комплект в HomeCinema: серверный Compose, каталог 0.7.4, Windows bridge с API запоминания дорожек, Android инструкции, резервное копирование и экспорт текущих контейнеров для переезда.

Включены текущие исправления: дисковые постеры KP, SQLite WAL access, aliases ID (F1), обновление URL кэша постеров, экспорт online_watched_last и предзагрузка для items_line/каталогов. Реальные адреса и профили заменены конфигурацией.

Добавлены TODO переключения аккаунтов и сохранения их настроек. Чистая установка и восстановление реального экспорта требуют отдельной проверки; известные ограничения перечислены в docs/KNOWN_ISSUES.md.
