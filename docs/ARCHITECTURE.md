# Архитектура

Docker Compose запускает Lampac, TorrServer, каталог и кэш постеров в общей сети. Серверные запросы используют имена сервисов; клиентские URL генерируются из `config/stack.env`, чтобы телевизоры могли обращаться по LAN.

`server/scripts/render.py` берёт исходный `lampainit.js` из образа Lampac, добавляет текущий клиент каталога и bootstrap, Family Watch, Prefetch, постеры и mpv bridge. Сгенерированные файлы не хранятся в Git. Шаблоны клиента находятся в `server/recommender/*.js.template`; bridge — в `server/templates/`.

`server/data/` содержит отдельные постоянные данные каждого сервиса. Каталог сохраняет SQLite и кэш выдачи. Постеры находятся в `poster-cache/posters/*.img`; таблица исправлений ID — рядом в `poster-overrides.json`. Кэш изображений читает каталог через SQL `mode=ro`, но bind-каталог подключён `rw` для необходимых SQLite WAL sidecar-файлов.

История и тайм-коды Lampac хранятся независимо от указателя последней серии. Исправление пропущенного события синхронизации не заменяет полноценное разрешение конфликтов между устройствами.

`config/profiles.json` сейчас выбирает профиль только при установке. Переключение аккаунтов и серверные настройки аккаунта запланированы в TODO.
