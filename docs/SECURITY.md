# Конфигурация и данные

Проект предназначен для домашней LAN. Порты сервисов публикуются на хосте; общая настройка аутентификации внешнего reverse proxy в комплект не входит.

Реальные `stack.env`, `profiles.json`, пароли, базы, история просмотра и архивы исключены из Git. Резервные копии содержат личные данные, храните их отдельно. Публичность профиля Кинопоиска необходима для загрузки списка оценок; ID задаётся владельцем.
