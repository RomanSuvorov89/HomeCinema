# Ограничения

- Общий установщик 0.3.0 ещё не проверен на чистой машине. Не заменяйте им действующую установку без резервной копии.
- Не все образы и зависимости закреплены по digest. Для точного переезда сохраняйте работающие образы отдельно.
- Family Sync отправляет целый снимок `sync_view`; одновременные изменения и возврат старого устройства могут вызывать конфликты. Тайм-коды и последняя серия — разные записи.
- Исправления истории конкретных сериалов не являются миграцией для всех пользователей.
- После изменения URL/ID изображений может потребоваться полный перезапуск приложения или Ctrl+F5. При отсутствии KP ID остаётся исходная картинка; доступ к TMDB может зависеть от сети.
- Windows bridge после сна пока требует отдельной диагностики.
- Создание APK может требовать Android Build Tools/zipalign в Lampac. Веб-версия доступна без APK.
- Для воспроизведения на ТВ качество звука, дорожки и субтитры зависят от выбранного внешнего плеера.
- Переключение профилей и серверное сохранение основных настроек реализованы. Импорт второго аккаунта Кинопоиска и произвольных настроек сторонних плагинов пока не подключён; профили с активным входом CUB используют штатный интерфейс CUB.

- Извлечение постеров Киноафиши проверено на HTML-фикстурах. При изменении разметки, отсутствии точного совпадения названия/года или сетевой ошибке используется запасной постер КП; реальная выдача изображений требует проверки с домашнего сервера. Логи показывают выбранный источник.

- Если кадр серии недоступен, клиент показывает постер сезона с пояснением в title. Источником настоящих кадров служат зеркала TMDB штатной Lampa; новый дисковый кэш требует живой проверки.

- Кэш 0.3.1 получает TMDB через nl.imagetmdb.com и de.imagetmdb.com. Пользователь подтвердил полный JPEG с обоих зеркал из контейнера. Lampac /tmdb/img/ при сетевой ошибке возвращает редирект, поэтому не используется как источник байтов для кэша. Обновление проверяет контрольное изображение до активации клиента.

- Для превью нужны и изображения, и метаданные seasons/still_path. В 0.3.2 запросы сезонов перенаправлены в локальный API-кэш через Cloudflare DoH; успешный ответ источника подтверждён из контейнера пользователя, новое подключение требует проверки после обновления.

- Факты КП: реальная разметка didyouknow пока не подтверждена из домашнего контейнера. При капче/неподдержанной разметке остаётся сохранённый текст либо сообщение и ссылка на источник. Отдельный CUB аккаунт для этого экрана не используется.

- Стрелка назад с корневой карточки исправлена; пользователь подтвердил работу.

- Пользователь подтвердил подключение Яндекс Диска на текущем сервере. Загрузка/восстановление реальной копии и ввод секретов на ТВ ещё требуют проверки. Нужны своё OAuth-приложение и отдельно сохранённый пароль копий.
- Облако сохраняет поддерживаемые профили/таблицы и настройки устройств; произвольные плагины, авторизации, Lampac SQLite, Compose и кэш изображений туда не входят. Одновременные дома пишут отдельные версии без автоматического слияния. См. CLOUD.md.

- Установщик одной командой и старт без KP ID реализованы; настоящий полный прогон Docker на новой ОС ещё не выполнен. Вход Яндекса и пароль копии требуют действий пользователя. На существующем ПК с занятыми портами чужие сервисы не останавливаются. См. ONE_COMMAND.md.

- Новые правила главной, фильтра сезонов и «Буду смотреть» проверены автоматически; применение на домашних ПК/ТВ ещё не подтверждено. Старый сезонный фильтр сбрасывается однократно, поскольку сохранённая запись не позволяет отличить личный выбор от унаследованного общего значения.
