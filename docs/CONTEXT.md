# Контекст проекта — 20 октября 2026

Репозиторий HomeCinema создан владельцем для всех дальнейших работ и воспроизводимой установки после переезда. Не связан с другими рабочими репозиториями пользователя.

Текущая установка: CachyOS, управление с Windows через SSH/fish. Lampac, kinopoisk-sync, TorrServer и roman-poster-cache запущены отдельными контейнерами; Lampac управляется Portainer. Новый общий Compose не применяется к ним автоматически. Не запускать его на тех же портах одновременно.

В Git сохранены последний доступный код каталога 0.7.4, ранее подготовленный Windows/Android комплект и доработки текущего сеанса. Работающая серверная копия может содержать дополнительные настройки; перед переносом нужен экспорт по MIGRATION.md.

Проблемы и исправления:

1. TMDB возвращал сетевые/TLS ошибки; прокси Lampac перенаправлял к тому же недоступному источнику. Добавлен самостоятельный дисковый кэш постеров KP.
2. SQLite каталога с WAL не открывалась при bind `ro`; каталог подключён `rw`, SQL остаётся `mode=ro`.
3. Для F1 CUB отдавал ошибочный ID: добавлена общая таблица aliases и обновлён URL клиентского кэша.
4. Штатная синхронизация включала `online_watched_last` в payload, но не подписывалась на его изменение. Добавлен обработчик экспорта. Ручные значения истории не включены в дистрибутив.
5. Предзагрузка не срабатывала из-за фильтра контроллера. Реальный контроллер главной — `items_line`; после добавления пользователь подтвердил работу.

Открытые задачи: переключение аккаунтов, сохранение их настроек, конфликты синхронизации, bridge после сна, чистая установка. См. TODO.md.

Расписание «Теда Лассо»: в базе есть оценка, но KP отдаёт четвёртый сезон с годом без точных дат, IMDb ID отсутствует. Добавлен общий fallback для неполных расписаний в episode_schedule.py, без привязки к сериалу. Сетевой результат на сервере пользователя пока не подтверждён.

TVmaze оказался недоступен с сервера пользователя напрямую и через имеющийся SOCKS. Киноафиша и MyShows отвечают 200. По выбору пользователя Киноафиша стала основным источником расписания, Кинопоиск резервным. Парсер строк написан по HTML newSeriesList_item, полученному с его сервера. Общее сопоставление и установка ещё требуют проверки на живом сервере; установщик сначала проверяет конкретный сериал без изменения базы. Постеры пока не переключались.
