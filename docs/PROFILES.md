# Профили HomeCinema

Кнопка аватара в верхней панели открывает «Кто смотрит?». Можно добавить профиль, переключиться, переименовать текущий или сохранить его сейчас. Выбор действует на конкретном устройстве. Один профиль можно одновременно использовать на нескольких ТВ и ПК.

## Сохранение существующих данных

Основной профиль использует существующий ID каталога и прежнюю пустую область `lampac_profile_id`. Его оценки Кинопоиска, отложенное и рекомендации остаются на своих местах. Новым профилям выдаются отдельные ID и области Lampac.

При первом открытии каждого старого устройства его личные данные читаются через Lampa.Storage, включая значения из резерва IndexedDB. Первый снимок каждого устройства сохраняется в home_profile_backups. История добавляется к серверной, более старые тайм-коды не заменяют новые. При первоначальном слиянии последняя серия выбирается по более позднему сезону/эпизоду; обычное повторное воспроизведение учитывает время обновления.

Смена профиля сначала сохраняет текущие изменения и получает целевой снимок. Затем происходит перезагрузка страницы; данные другого профиля применяются на новой странице. Старые сетевые запросы завершаются в прежнем контексте. Если сервер недоступен, переключение отменяется. Кеши личных оценок, рекомендаций и полок получают пространство имён профиля. События закладок WebSocket проверяются по области профиля.

Сохранённые поля: favorite, file_view, online_watched_last, online_view, online_last_balanser, torrents_view, torrents_filter_data, kp_rating, timetable, тема HomeCinema, языки интерфейса/каталога, источник каталога, размер постеров, порядок меню/кнопок, громкость интерфейса, качество видео, запуск/сдвиг субтитров, нормализация звука, фильтры рекомендаций, скрытые карточки, история поиска и прочитанные уведомления.

Адреса серверов, пароли, API-ключи, идентификаторы устройства, список плагинов, громкость плеера и способ его запуска остаются на устройстве. Произвольные настройки сторонних плагинов автоматически не экспортируются.

Изменения отправляются относительно последнего известного снимка. Для истории используется слияние отдельных записей. Если одно личное скалярное значение изменилось на двух устройствах, сервер возвращает конфликт. В меню можно восстановить настройки с сервера или явно сохранить локальные настройки вместо серверных. Исходные снимки остаются в резервной таблице.

## Уведомления

Колокольчик открывает новые серии оценённых сериалов за последние 30 дней. Для каждого сериала показывается последняя серия по расписанию. «Не интересно» и отключённое отслеживание учитываются. Наличие перевода или раздачи не проверяется и явно отделено от даты выхода. При наличии сохранённого сопоставления нажатие открывает карточку сериала. Список прочитанного хранится в профиле. Ошибка сохранения профиля отмечается значком «!».

## Обновление существующей установки

Сохраните scripts/update-profiles.sh из выбранного коммита и выполните:

```sh
bash update-profiles.sh COMMIT_SHA /path/to/kinopoisk-sync /path/to/lampainit.js
```

Установщик сохраняет SQLite backup баз каталога и Lampac и копии исходников в `data/backups/before-profiles-*`. Он заменяет только Handler и card_ratings в текущем kp_sync.py, сохраняя существующие настройки и другие функции. Текущие адреса берутся из установленного клиента. Файлы .env и Compose не заменяются.

Новый образ сначала собирается и проходит `python -m unittest test_profiles` на временных базах. Только после этого сервис обновляется, проверяется API профилей, подключается центральный JS и перезапускается Lampac. Inode смонтированного lampainit.js сохраняется. После установки — Ctrl+F5 на ПК и полное закрытие/открытие Lampa на ТВ. Для первоначального сохранения истории откройте все использовавшиеся устройства сначала в основном профиле.

## Границы первой версии

- Импорт Кинопоиска и фоновый расчёт персональных полок пока подключены к основному профилю. Новые профили начинают с отдельной пустой истории, настроек и собственных отметок; подключения второго источника оценок Кинопоиска через интерфейс пока нет.
- Профили предназначены для домашней установки. При активном входе в аккаунт CUB модуль HomeCinema не подключается к кнопкам и не меняет его настройки.
- Старые клиенты, которые ещё не обновлены, продолжают работать с прежним Family Sync. Его ограничения по конфликтам целого sync_view сохраняются. Для полного переноса локальной истории нужно открыть каждый клиент после обновления.
- Автоматически проверены серверные запросы, разделение данных, снимки, конфликты, IndexedDB-чтение, смена страницы, кнопки, ошибочные запросы и установщик. Реальный телевизор, его пульт и используемая версия Lampac требуют проверки после установки.
- Перед возвратом к старому центральному JS переключите устройства в основной профиль. Сохранённые профили и резервные копии баз не удаляются.

Обновление `scripts/update-profiles.sh REF` также обновляет клиент существующего кэша постеров (необязательный четвёртый аргумент — его каталог). Контейнер постеров пересобирать не требуется. Обновлённая шапка изолирует кнопки от обработчиков CUB; счётчик расположен внутри кнопки. После установки полностью перезапустите приложение, чтобы закрыть оставшееся старое окно CUB.
