# Состав

- Lampac/Lampa с централизованными клиентскими плагинами, TorrServer и семейной синхронизацией.
- Каталог Кинопоиска, оценки, локальный кэш главной страницы и страниц «Ещё», рекомендации и запоминание дорожек. Исходная версия компонента: 0.7.4.
- Постеры загружаются с Кинопоиска по известному ID и сохраняются на диск. Соответствия берутся из каталога и закладок Lampac. Неподтверждённое совпадение по названию не используется.
- Общий файл `poster-overrides.json` исправляет ошибочные внешние ID; включён случай F1. Параметр `v=2` меняет старый клиентский URL изображения.
- Family Watch отправляет изменения последней серии в штатный `sync_view`. При запуске устройства принудительный экспорт не выполняется.
- Prefetch учитывает геометрию списка и вызывает штатные загрузчики заранее, без переключения фокуса. Поддерживаются контроллеры `content` и `items_line`.
- Windows: mpv.net, локальный bridge, конфиги аудио и Lua выбора субтитров. Требуется проверка конкретной установки, особенно выхода из сна.

Пользователь подтвердил работу локальных постеров, исправления F1 и окончательной предзагрузки. Указатель Эйфории и Ричера исправлялся вручную; такие персональные значения в установку не включены. Для синхронизации нужна проверка следующего реального просмотра на ТВ. Весь объединённый установщик пока имеет статус preview.

Детальная история компонента каталога находится в `server/recommender/history/`. Это исторические заметки предыдущих пакетов; актуальные команды общей установки приведены в корневом README.

Основной источник расписаний — Киноафиша. Загрузчик ищет сериал на сайте, принимает только единственное совпадение названия и года премьеры и сохраняет URL в `episode_schedule_links`. Даты читаются из отдельных `newSeriesList_item`, а не из рекламы или новостей. Загружаются два последних объявленных сезона; будущий сезон без дат не активирует старый просмотренный сезон.

При недоступности Киноафиши используется расписание Кинопоиска с явным предупреждением о неполных датах. Прежние подтверждённые серии сохраняются. `episode_schedules.error` содержит причину перехода на резервный источник. TVmaze из автоматической загрузки удалён. Постеры пока по-прежнему хранятся в отдельном кэше Кинопоиска.

Для существующей отдельной установки предусмотрен `scripts/update-episode-source.sh`: он загружает код по точному коммиту, проверяет источник на указанном сериале до изменения приложения, сохраняет резервные копии и пересобирает только рекомендатель.

В карточке кнопка «Для меня» открывает меню отметок. «Не интересно» убирает карточку из продолжения и рекомендаций при следующем построении главной; «Снять отметку» разрешает её снова. Оценки Кинопоиска, история и тайм-коды при этом не удаляются. Личная оценка отображается в метаданных; круглый значок истории на постерах скрыт как декоративный.
