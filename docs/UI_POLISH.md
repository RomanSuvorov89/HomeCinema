# Стрелка назад, личная оценка и факты

`update-ui-polish.sh COMMIT_SHA [CATALOG_DIR] [LAMPAINIT] [POSTER_DIR]` использует существующий установщик каталога/профилей: резервные копии SQLite и исходников, пересборка текущего сервиса, тесты профилей, сохранение inode центрального JS, восстановление порядка профилей/клиента изображений и перезапуск Lampac. Тема и сервер изображений не пересоздаются.

Стрелка `.head__backward` обрабатывается одним capture-click. При открытом верхнем окне возвращается его контроллер и выполняется закрытие. Без окна при наличии предыдущего экрана вызывается Activity.backward напрямую, чтобы потерявший фокус контроллер не проглотил нажатие. Если после восстановления карточки/прямой ссылки в истории всего один экран, стрелка заменяет его главной через Activity.replace с clear=true (без параметров карточки). На самой главной повторное нажатие ничего не пересоздаёт. Клавиатурные сочетания, поле ввода и другие кнопки не перехватываются. Нужна проверка конкретного поведения мыши на ПК пользователя.

Капсула личной оценки получает минимальную высоту 1.5em (как штатная оценка), автоматическую ширину, отступы и перенос всей капсулы вместе с остальными оценками. Текст остаётся в одну строку. Само значение и цвета темы не меняются. Проверены стили и сценарии DOM; пиксельная проверка на реальном экране остаётся за пользователем.

Штатный компонент ai_facts обращается к CUB AI, а не к опубликованным фактам. Собственный компонент читает `/facts/kp/ID.json?type=tv|movie`, показывает текст Кинопоиска, источник и скрывает помеченные спойлеры до нажатия. Текст вставляется через text(), не HTML. При отсутствии KP ID показывается понятное сообщение. При ошибке источника показываются ошибка, описание карточки и ссылка на источник, без предложения входа CUB и без выдуманных фактов.

Сервер читает didyouknow и при необходимости основную страницу Кинопоиска. Парсер принимает только коллекции facts/trivia, типы Fact/Trivia или отмеченные HTML-блоки; описания рекомендаций не превращаются в факты. Проверяются canonical и явный ID владельца факта. JSON-кэш общий для публичных фактов, лежит рядом с данными каталога в facts/, живёт 7 дней. При капче остаётся сохранённый текст; пустая выдача и ошибки повторяются не чаще раза в 5 минут. Куки и платный API не требуются.

В этой среде настоящая страница Кинопоиска недоступна. Парсер проверен на структурированных/HTML-фикстурах, извлечение фактов с текущей разметки сайта пользователя пока не подтверждено. Установщик выводит фактическое число извлечённых фактов контрольной карточки; нулевой результат не отменяет исправления стрелки и капсулы, но требует проверки разметки/доступности Кинопоиска.

Лог пользователя подтвердил остаточный сбой: click → backward → backward:after, component=full и screens=1 на каждом нажатии. В исходниках Lampa backward намеренно возвращает управление без перехода при одной активности. Это отдельный случай от потери фокуса контроллера; исправление корневого экрана проверено автоматическим сценарием, живая проверка ещё нужна.
