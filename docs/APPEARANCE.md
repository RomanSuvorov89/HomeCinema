# Оформление Apple TV

Тёмный графит, сдержанный фон, белый фокус, округлённые постеры и спокойные панели. На постерах сохраняются все имеющиеся оценки: КП, IMDb, каталог, личная оценка и прогноз. Капсулы платформ сохраняют фирменные цвета. Слой canvas с размытым цветным фоном скрывается только при включённой теме. Размеры карточек и навигация Lampa сохраняются. Внешние шрифты и библиотеки не загружаются.

Переключение на конкретном устройстве: **Настройки → Интерфейс → Оформление HomeCinema → Apple TV / Стандартный вид**. Применяется сразу. Выбор сохраняется локально на устройстве; общей синхронизации настроек аккаунтов пока нет.

Для общей установки задайте `APPLE_TV_THEME=1` в `config/stack.env` и выполните установку/обновление по README. Значение `0` исключает тему из сгенерированного центрального скрипта.

Для существующей установки используйте `scripts/set-apple-theme.py --path /path/to/lampainit.js --ref COMMIT_SHA`, затем перезапустите Lampac и клиент. Скрипт создаёт резервную копию, сохраняет inode Docker bind mount и добавляет только отдельный блок темы.

Полное удаление темы с сервера, без интернета:

```sh
python3 /path/to/set-apple-theme.py --path /path/to/lampainit.js --remove
docker restart lampac
```

Затем полностью перезапустите Lampa на ТВ или Ctrl+F5 в браузере. Удаляется только блок темы, остальные исправления не откатываются. Выбор в браузерной консоли также доступен через `HomeCinemaAppleTheme.setEnabled(false)`.

Проверены сборка CSS в центральный JS, переключение, сохранение выбора и удаление без повреждения соседних плагинов. На конкретных телевизорах визуальное оформление и управление пультом требуют проверки после установки.
