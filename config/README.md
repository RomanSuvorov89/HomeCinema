# Конфигурация

Файлы `*.example.*` безопасно передавать друзьям. Заполненные `stack.env` и
`profiles.json` персональны и не должны попадать в публичный архив.

- `stack.env` — сетевые адреса, порты, пароль и скорость фоновой очереди;
- `profiles.json` — профили Кинопоиска и пространства Family Sync;
- `rating-scale.json` — смысл оценок и utility активного профиля;
- `ACTIVE_PROFILE_ID` выбирает единственный активный профиль текущей preview.

При смене IP/DNS повторно запустите `server/install.sh`, затем переустановите
Windows-мост с новым `-ServerUrl`.
