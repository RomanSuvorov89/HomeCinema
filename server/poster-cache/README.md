# Кэш постеров и дат серий 0.2.1

В общей установке запускается автоматически, данные лежат в `server/data/poster-cache`. Плагин заменяет постеры по известному KP ID или точному соответствию из каталога/закладок. Изображения сохраняются на диск. Для сериалов источники проверяются по порядку: постер сезона на Киноафише → основной постер Киноафиши → Кинопоиск. Для фильмов сохраняется Кинопоиск. Неизвестные карточки и ошибки сохраняют исходное изображение.

Включены исправления действующей установки:

- каталог SQLite подключён `rw` для WAL sidecar-файлов, SQL открывается `mode=ro`;
- `data/poster-overrides.json` содержит общие исправления внешних ID, включая F1;
- клиентские URL используют `?v=3&season=N`, старый дисковый кеш КП не блокирует обновление;
- сезон берётся из `season_number` карточки, затем `online_watched_last`, затем последнего вышедшего сезона по расписанию; без этих данных выбирается основной постер;
- Киноафиша сопоставляется по точному названию и году; используется сохранённая ссылка расписания либо поиск с такой же проверкой;
- сезон запрашивается только по ссылке с подтверждённой страницы сериала. При ошибке изображения пробуется основной постер, затем КП;
- постеры Киноафиши повторно проверяются через сутки, запасной КП — через 6 часов; при полной недоступности сети сохраняется ранее записанное изображение. В браузере кеш — один час;
- для каждого сезона отдельные `.v3.sN.img` и `.json` с источником и временем проверки. Старые `.img` и исправления ID сохраняются.

Для существующей установки сразу с исправлением меню и темы используйте `scripts/update-appearance-posters.sh COMMIT_SHA RECOMMENDER_DIR POSTER_DIR LAMPAINIT`. Скрипт сохраняет текущие `.env`, каталоги данных, адреса и inode центрального файла. Он пересобирает существующие сервисы `kinopoisk-sync` и `poster-cache` и перезапускает Lampac. Исходники и центральный файл предварительно копируются.

В логах после нового запроса: `poster saved: ... season: ... source: kinoafisha-season`, `kinoafisha-main` или `kinopoisk`. Разметка извлечения постеров проверена на HTML-фикстурах; фактические изображения и сетевые ответы с домашнего сервера нужно проверить после установки. Расписание Киноафиши уже подтверждено пользователем.

## Только для существующей отдельной установки

Этот способ не нужен при использовании общего server/docker-compose.yml. Он сохраняет старое имя контейнера `roman-poster-cache`, чтобы не менять привычные команды диагностики.

```sh
cd server/poster-cache
cp config.env.example .env
```

В `.env` укажите доступные телевизорам POSTER_BASE/LAMPAC_URL, настоящий каталог баз CATALOG_DIR, путь LAMPAINIT и текущий семейный токен. Вместо localhost нужен LAN-адрес сервера. Затем:

```sh
bash install.sh
```

Перед изменением центрального JS установщик проверяет загрузку изображения, сохраняет резервную копию, сохраняет inode bind mount и перезапускает контейнер `lampac`. Сервисы не должны одновременно использовать порт общей установки.

Диагностика: `docker logs --tail 60 roman-poster-cache`, `curl -fsS http://SERVER_IP:9121/health`. Поле `catalog_errors` должно быть пустым после прогрева. `/index.json` содержит точные соответствия ID/путей. Кэш на диске сохраняется при `docker compose down`.

Для удаления только дополнения: `bash uninstall.sh`. Файлы изображений остаются на диске. После изменения полностью перезапустите Lampa либо Ctrl+F5 в браузере.

В карточке сериала и списке файлов торрента битые изображения серий (`full-episode` / `season-episode` / `torrent-serial`) заменяются постером сезона. При зависшей загрузке запасной постер появляется через 7 секунд. Это обозначено подсказкой «Постер сезона — кадр серии недоступен»; доступные настоящие кадры остаются. Для сезона из строки файла выбирается его номер, иначе используется текущий сезон сериала.


Для существующей установки: `bash scripts/update-series-assets.sh COMMIT_SHA [POSTER_DIR] [CATALOG_DIR] [LAMPAINIT]`. Обновляет только server.py и posters.js с копиями, пересобирает существующий сервис poster-cache, проверяет endpoint, устанавливает клиент и перезапускает Lampac. `.env`, данные, темы, профили и Portainer stack сохраняются.

`/series/kp/ID.json` возвращает только номера и подтверждённые даты серий из существующей `episode_schedules` в recommender.sqlite3. Запрос не запускает парсинг сайтов. Клиент подставляет отсутствующую дату в `.torrent-serial__line`; уже известную дату не заменяет. При отсутствии записи прочерки сохраняются. Чтение SQL выполняется в режиме `mode=ro`.

Дополнительно обработаны `.explorer-card__head-img > img` (постер раздела торрентов) и `data-src` изображений `.torrent-serial__img`, которое Lampa повторно применяет при lazy render. Событие `torrent_file:render` даёт точные сезон/серию/карточку без догадки по имени файла. Битый SVG в `.full-start__background` скрывается; настоящий доступный фон сохраняется. Самостоятельный источник настоящих кадров и фоновых изображений остаётся открытой задачей.
