# 0.7.2: премьера сезона и персональные списки

Расписание обрабатывается одинаково для всех сериалов. Будущая первая серия
нового сезона не активирует сериал. Сезон может попасть в «Продолжить просмотр»
с дня своей премьеры при наличии личной оценки. Недавняя серия остаётся
актуальной 30 дней; предстоящая серия уже начавшегося сезона — в пределах 45 дней.
Ручная история просмотра Lampa остаётся независимой от этой автоматической группы.

«Огонь» и «Сейчас смотрят» имеют отдельные персональные записи в home-cache.sqlite3.
Оценённые на Кинопоиске и помеченные просмотренными/неинтересными карточки исключаются.
В этих разделах фильмы старше текущего года минус четыре и явное TS/CAM/TC/SCR
качество исключаются. Год первого сезона не используется для отсева сериалов.
«Огонь» сохраняет исходный порядок CUB. «Сейчас смотрят» сочетает этот порядок
с умеренным множителем прогноза, без бонуса за личную оценку.

Прогнозы и остальные доступные поля берутся из готового отчёта кандидатов,
сохраняются отдельно от общей карточки и не передаются другим профилям.
Если у CUB-карточки ещё нет связи с метаданными/отчётом кандидатов, прогноз
не выдумывается: такая карточка может остаться без прогноза. Это ограничение
покрытия каталога, а не ошибка калибровки. Формула прогноза не меняется.

Публикация персонального ряда заменяет общий ряд только для владельца.
При сетевой ошибке сохраняется последний готовый персональный список.
Локальный снимок главной меняет ключ на v3, чтобы старые ошибочные списки
не возвращались из браузерного/TV хранилища. Данные рейтингов и история сохраняются.
HTTP-чтение главной по-прежнему не выполняет интернет-запросов.

После установки дождаться первой записи `home cache` новой версии и открыть
главную повторно. Метаданные не сбрасываются и не скачиваются повторно целиком.
APK, MPV Bridge, выбор плеера и установленные внешние расширения не меняются.

Проверки: 43 Python теста и 9 JavaScript сценариев; в том числе будущая премьера,
первый день сезона, порядок дат, сохранность кеша без сети и изоляция профилей.
Физический Android TV проверяется после установки пользователем.
