# Проверка рекомендаций в Lampa

Актуальное поведение 0.5.0 и формула v3 описаны в HOME.md. Основная строка
теперь ограничена последними пятью календарными годами, архив отделён.

Главная CUB: строка «Рекомендация AI» заменяет «Рекомендуем посмотреть».
«Ещё» открывает полный список. Над списком расположены кнопки фильтров:
тип, конкретный год, минимальная оценка КП, страна, жанр и сохранённая отметка.
Сортировка: релевантность, новые, КП, число оценок и название. Настройки фильтров
сохраняются в браузере; сами ответы по-прежнему на сервере.
Карточки загружаются страницами по 12 из всех рассчитанных кандидатов (при
отсутствии candidate_scores используется Top-50 отчёта). Они разрешаются через каталог Lampa так же, как список
«Кинопоиск: Буду смотреть»; для обложек и стандартной страницы фильма нужен
работающий поиск TMDB в Lampa. Не найденные карточки пропускаются; список пропусков
доступен в меню фильтров. Всплывающего сообщения при прокрутке больше нет.
Снимок данных фиксируется на время открытия списка для стабильной пагинации.
Повторное открытие обновляет снимок.

В открытой карточке доступны три отметки: «Хочу посмотреть», «Не интересно»,
«Уже смотрел», а также «Почему предложено». Повторное нажатие выбранной отметки
снимает её. Неудачный запрос не показывает отметку как сохранённую.

Ответы хранятся в `recommendation_feedback` внутри `data/recommender.sqlite3`.
Ключ `(profile_id, kp_id)`, поля `status`, `updated_at` (UTC Unix seconds).
FK указывают на profiles и media. Текущий профиль определяется серверной переменной
KINOPOISK_PROFILE_ID, а не присланным клиентом полем. Несколько профилей могут
храниться раздельно; переключатель профиля ещё не реализован.

GET /review.json возвращает карточки и актуальные отметки для текущего профиля.
POST /review-feedback.json принимает {"kp_id":42,"status":"want"}.
Допустимые статусы: want, not_interested, seen, clear. clear удаляет отметку.
Сервис предназначен для домашней доверенной сети, авторизация API не добавлена.

Отметки пока собираются для проверки, не меняют оценки/списки на Кинопоиске,
не отмечают серии просмотренными в Lampa и не влияют на ранжирование.
Карточки остаются в проверочном списке, чтобы ответ можно было изменить.
Отметки других устройств обновляются при повторном открытии списка.
predicted_rating показывается отдельной плашкой «Прогноз ≈ 7.4», с одним
десятичным знаком. Это предварительное преобразование preference_score в шкалу 1–10,
а не проверенный прогноз точности или личная выставленная оценка.
Личная оценка остаётся целым числом в плашке «МОЯ».

Главная использует до 12 кандидатов на строку, исключая отметки seen/not_interested.
Полный список сохраняет эти карточки для изменения обратной связи.
Интеграция оборачивает только Api.sources.cub.main и его постраничный callback.
Новые строки вставляются в начало главной. При недоступности сервиса
или поиска в течение 8 секунд остаётся штатная главная. Повторное открытие
главной использует подготовленный снимок (кэш до 60 секунд).
«Ещё» использует params.emit.onlyMore; для старых версий Activity.push
перехватывает только URL roman-ai://recommendations. Другие переходы не меняются.

Известные ограничения: формула ещё предварительная; подозрительные метаданные
и неверно определённые темы пока не исправлены. Нужна проверка интерфейса
на установленной версии Lampa и затем на телевизоре.

Установочный архив должен сохраняться и скачиваться строго как kinopoisk-sync.tar.gz.
Обновление рекомендателя не содержит установщиков Windows и не изменяет MPV Bridge.
