# Запоминание дорожек — 0.4.1, предварительная версия

Содержит также главную «Рекомендация AI» версии 0.4.0: отдельно устанавливать
предыдущий архив не нужно.

## Правило выбора

Для сериала восстанавливаем сохранённую озвучку и субтитры независимо друг от друга.
Сопоставляем язык (ru/rus/ru-RU эквивалентны), нормализованное название и признак
forced. Номер дорожки, кодек и число каналов не являются её идентификатором.
При нескольких неоднозначных совпадениях применяется запасной выбор.

Если предпочтение отсутствует или дорожка не найдена:

1. Озвучка: русская с пометкой «дубляж»/dub, затем другая русская.
   Если русских дорожек нет, оставляем выбор плеера.
2. Субтитры: русские с пометкой full/полные, затем русские нефорсированные
   без такой пометки. Если таких нет, субтитры отключаются.
3. Автоматический запасной выбор НЕ записывается вместо предпочтения.
4. Явное отключение субтитров пользователем запоминается для сериала.

У фильмов применяется тот же запасной выбор, но ручной выбор не переносится
на другие фильмы. Без устойчивого ID сериала работает только запасной выбор.
Полноту дорожки и дубляж определяем по метаданным; по самому звуку/тексту
анализ не проводится. Без корректных названий нельзя гарантировать студию или дубляж.

## Установка поверх существующей системы

Скопировать свежий kinopoisk-sync.tar.gz в /home/USER. В Linux (fish):

```fish
cd /home/USER/kinopoisk-sync
and tar -xzf /home/USER/kinopoisk-sync.tar.gz -C /home/USER/kinopoisk-sync
and docker compose up -d --build --force-recreate
and fish roman-mpv-bridge/linux/install-lampa-plugin.fish
```

Последний шаг обновляет существующий блок MPV в lampainit.js с резервной копией
и перезапускает Lampac. Перед установкой закончите воспроизведение.

В PowerShell Windows, запущенном от администратора под обычной учётной записью Roman:

```powershell
$dest = "$HOME\Downloads\kinopoisk-track-update"
New-Item -ItemType Directory -Force -Path $dest | Out-Null
tar -xzf "$HOME\Downloads\kinopoisk-sync.tar.gz" -C $dest
if ($LASTEXITCODE -ne 0) { throw 'Archive extraction failed' }
Set-ExecutionPolicy -Scope Process Bypass
& "$dest\roman-mpv-bridge\windows\update-tracks.ps1"
```

Обновляет только исполняемый скрипт установленного Bridge. Сохраняет config.json,
путь MPV, громкость, список разрешённых origins и задачу планировщика, включая
watchdog. На неуспешном health-check восстанавливает предыдущий скрипт.
Полный install-windows.ps1 повторно запускать не нужно.
Затем Ctrl+F5 в Lampa.

## Поддержка плееров и ограничения

- MPV через обновлённый Bridge: чтение дорожек из JSON IPC; установка aid/sid.
  Начальный выбор после готовности файла, обычно в пределах очередного опроса
  (2 секунды). Ручной выбор сохраняется при следующем опросе. Оставьте вкладку
  Lampa открытой; не закрывайте MPV мгновенно после переключения дорожки.
- Встроенный плеер Lampa: события PlayerVideo tracks/subs, переключение доступных
  плееру объектов дорожек. Наблюдение ручного выбора каждые 750 мс.
- Внешние Android-плееры пока не поддержаны. На Android/webOS встроенная
  обработка зависит от того, предоставляет ли плеер дорожки JavaScript.
  Проверка на физических ТВ ещё впереди; API webOS может скрывать часть дорожек.
- Если видео перекодировано в единственную аудиодорожку, выбор другой исходной
  озвучки требует поддержки на стороне GStreamer; этот модуль её не добавляет.
- Ошибка сохранения на сервере отображается уведомлением; работа видео продолжается.
- Сопоставление источников с разными ID ограничено: kp:tv:N, tmdb:tv:N и cub:tv:N
  являются разными ключами. Используйте одинаковые карточки каталога на устройствах.

## Данные и архитектура

Таблица `track_preferences` в существующей recommender.sqlite3 создаётся лениво.
PRIMARY KEY `(profile_id, series_key, kind)`; kind audio/sub; descriptor — JSON
{lang,title,forced,full,off}; updated_at — UTC Unix seconds.
Оценки, таймкоды и библиотека не меняются. Профиль определяется сервером
KINOPOISK_PROFILE_ID. Архитектура допускает несколько профилей; переключателя ещё нет.

GET /track-preferences.json?series_key=kp:tv:123 → preferences.
POST /track-preferences.json → {series_key,kind,descriptor}.
Сервер принимает только допустимые ключи и поля; ID дорожки в БД не сохраняется.
Модуль track-memory.js автоматически включается в ответ /kinopoisk.js.
URL сервера берётся из настройки основного плагина (window.RomanTracksApi).

Bridge GET /status теперь возвращает tracks, aid, sid; POST /track-selection
принимает {id,selection:{aid:integer,sid:integer|"no"}}. Проверяет сессию и реальные
ID дорожек; существующее ограничение Origin сохранено. Браузер не может послать
произвольную IPC-команду. Сервис рекомендаций по-прежнему для доверенной домашней сети.

Проверки: test_track_preferences.py, test_track_memory.cjs. Покрывают раздельность
профилей, изменение номеров/кодеков, forced/full, отсутствие предпочитаемой дорожки,
ручное отключение и запрет перезаписи предпочтений автоматическим запасным выбором.
Живой запуск в Windows и на ТВ в среде сборки недоступен.
