# HomeCinema

Домашний кинотеатр: Lampa/Lampac, TorrServer, локальный каталог и рекомендации по Кинопоиску, сохранённые постеры, синхронизация просмотра и Windows mpv.net bridge.

Репозиторий хранит исходники и команды для восстановления системы после переезда. **Версия 0.3.0 — preview:** отдельные исправления проверены на действующей установке; полная установка этого объединённого комплекта на чистую машину ещё требует проверки. Рабочую систему сейчас переустанавливать не нужно.

## Установка и обновление одной командой

На новом или уже настроенном Debian/Ubuntu или Arch/CachyOS с systemd:

```sh
bash -c 'f=$(mktemp) && curl -fSL https://raw.githubusercontent.com/RomanSuvorov89/HomeCinema/main/install.sh -o "$f" && bash "$f"; r=$?; test -z "${f:-}" || rm -f "$f"; exit "$r"'
```

Начальные конфиги, пароли, адреса и локальный профиль создаются автоматически; ID Кинопоиска заранее не нужен. После запуска откройте выведенный URL и восстановите дом с Яндекс Диска. Ввод ClientID/secret и подтверждение Яндекса остаются за пользователем; отдельного пароля новых копий нет. [Подробности и проверенные сценарии](docs/ONE_COMMAND.md). Ниже — прежняя ручная установка.

## Новая установка на Linux

Сначала установите Git и Docker с Compose. Для CachyOS/Arch:

```sh
sudo pacman -S --needed git docker docker-compose curl jq python
sudo systemctl enable --now docker
```

Клонируйте репозиторий, подготовьте настройки:

```sh
git clone https://github.com/RomanSuvorov89/HomeCinema.git
cd HomeCinema
cp config/stack.env.example config/stack.env
cp config/profiles.example.json config/profiles.json
cp config/rating-scale.example.json config/rating-scale.json
```

В `config/stack.env` укажите LAN-адрес нового сервера во всех четырёх `PUBLIC_*_URL`, пароль Lampac и активный профиль. В `config/profiles.json` заполните ID своего публичного профиля Кинопоиска и собственный `lampac_sync_id`. Адреса должны открываться с телевизоров. Желательно закрепить IP сервера в DHCP роутера.

Запуск, в том числе из fish:

```sh
bash server/install.sh
bash server/healthcheck.sh
```

Если у пользователя нет доступа к Docker, установщик использует `sudo docker`. Для диагностических команд и резервного копирования в таком случае также используйте `sudo`. Установщик умеет поставить зависимости через `bash server/install.sh --install-deps`.

| Сервис | Порт по умолчанию | Данные |
|---|---:|---|
| Lampac / Lampa | 9118 | `server/data/lampac` |
| TorrServer | 8090 | `server/data/torrserver` |
| Каталог и рекомендации | 9120 | `server/data/recommender` |
| Кэш TMDB / Киноафиши / Кинопоиска | 9121 | `server/data/poster-cache` |

На ТВ и ПК откройте `PUBLIC_LAMPAC_URL`. Центральный клиент подключает каталог, Family Sync, постеры, предзагрузку и bridge. Для Windows плеера: [инструкция](docs/WINDOWS.md). Для Android TV: [инструкция](android/README.md).

## Перенос существующей установки

**Код в Git не заменяет резервную копию истории и баз.** Перед переездом выполните [инструкцию экспорта и восстановления](docs/MIGRATION.md). Она охватывает нынешние отдельные контейнеры и новую общую установку.

Для установки из этого репозитория:

```sh
bash server/backup.sh /path/to/external-disk/homecinema
```

Скрипт останавливает работающие сервисы на время согласованного копирования SQLite и затем запускает их обратно. Архив содержит личную историю и настройки; храните его отдельно от публичного Git.

## Обновление и диагностика

Для установки через корневой установщик повторно выполните **ту же команду из раздела выше**: она скачает актуальный код, сделает локальный backup и обновит сервисы с сохранением настроек. [Пути, прежние отдельные сервисы и откат](docs/ONE_COMMAND.md).

Для ручного checkout по-прежнему можно использовать `git pull --ff-only` и `bash server/update.sh`, предварительно выполнив `bash server/backup.sh`.

Обновление пересобирает плагины из шаблонов, сохраняет прежний `lampainit.js` и не удаляет базы. После него полностью перезапустите Lampa на ТВ; в браузере нажмите Ctrl+F5. Образы Lampac и TorrServer используют `latest`; перед переездом сохраняйте фактические образы по инструкции, поскольку их будущие версии могут отличаться.

## Проверки исходников

Нужны Python 3, Node.js и bash. Команда `bash scripts/check.sh` проверяет шаблоны и синтаксис, серверные компоненты и клиентские сценарии без обращения к реальному серверу. Docker-сборка, Windows PowerShell и реальные телевизоры проверяются отдельно.

### Исправление меню, темы и сезонных постеров на действующем сервере

`scripts/update-appearance-posters.sh COMMIT_SHA RECOMMENDER_DIR POSTER_DIR LAMPAINIT` обновляет существующую установку с резервными копиями. Подробности выбора сезона и диагностики: [кэш постеров](server/poster-cache/README.md). Меню «Для меня» использует штатное закрытие Select без повторного вызова из onBack. Тема сохраняет все оценки и фирменные цвета платформ, убирает цветной canvas-фон. После обновления нужен полный перезапуск Lampa / Ctrl+F5.

## Профили и уведомления

Кнопка аватара открывает переключение профилей, создание и переименование. История и основные личные настройки сохраняются на сервере; выбор профиля действует на одном устройстве. Колокольчик показывает новые серии оценённых сериалов по расписанию. Импорт оценок Кинопоиска пока подключён к основному профилю. Установка на действующий сервер — `scripts/update-profiles.sh`, с резервными копиями и проверкой нового контейнера перед активацией. [Подробности](docs/PROFILES.md).

Исправление изображений внутри сериала и дат в списке торрентов для действующей установки: `scripts/update-series-assets.sh COMMIT_SHA` (с резервными копиями). Настоящие кадры не подменяются: если источник недоступен, показывается обозначенный постер сезона; битый декоративный фон скрывается. Подробности в [описании кэша](server/poster-cache/README.md).

Диагностика DNS TMDB без изменения настроек: `scripts/diagnose-tmdb.sh`; [результаты и ограничения](docs/TMDB_NETWORK.md). Преждевременный VPN-фикс удалён из активного набора; он не устанавливал причину первоначального сбоя.

Приоритет изображений: TMDB через проверенные зеркала Lampa с сохранением на диск → резервный постер Киноафиши → Кинопоиск. Обновление действующего кэша: `scripts/update-series-assets.sh COMMIT_SHA`. Перед подключением клиента скрипт проверяет реальную загрузку TMDB из контейнера. [Подробности](server/poster-cache/README.md).

Исправления стрелки «Назад», размера личной оценки и фактов без CUB: `scripts/update-ui-polish.sh COMMIT_SHA`. [Поведение и ограничения источника фактов](docs/UI_POLISH.md).

## Облачные копии без отдельного сервера

**R → Облачное сохранение → Яндекс Диск**: подключение по QR/коду, зашифрованная часовая синхронизация профилей и восстановление после переезда. Неизменившееся состояние не выгружается; просмотры ПК/ТВ объединяются по отдельным записям. Бот и VPS не нужны. Один раз требуется своё OAuth-приложение Яндекса; ключ копий сохраняется автоматически на Диске. DNS-адрес TorrServer переносится. **R → Подключённые сервисы — Кинопоиск** принимает ID/ссылку публичного профиля. Обновление действующей установки: `scripts/update-cloud.sh COMMIT_SHA`. [Подключение, состав копии и ограничения](docs/CLOUD.md). Реальный OAuth/Диск и ввод на ТВ ещё требуют проверки после установки.
