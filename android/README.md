# Android TV / Google TV

## Предварительный поддерживаемый способ

1. Откройте на телевизоре `PUBLIC_LAMPAC_URL` из `config/stack.env`.
2. Добавьте страницу на главный экран, если браузер/оболочка телевизора это умеет.
3. Все серверные плагины, TorrServer, Family Sync и рейтинги подхватятся без ввода
   URL с пульта.

## Установка APK через ADB

Включите на ТВ режим разработчика и сетевую отладку, затем выполните команды ниже.
Если `adb` отсутствует, скрипт установит Google Platform Tools через `winget`:

```powershell
adb connect IP_ТЕЛЕВИЗОРА:5555
Set-ExecutionPolicy -Scope Process Bypass
.\android\install-from-windows.ps1 -ServerUrl 'http://SERVER_IP:9118'
```

Lampac собирает APK под конкретный адрес сервера. Если endpoint возвращает ошибку
`zipalign not found`, APK пока не устанавливайте: используйте веб-версию. Добавление
Android SDK Build Tools в серверный образ отмечено задачей для следующей preview.

## Что ещё требуется проверить

- сохранение Family Sync после полного перезапуска приложения;
- выбор русских full-субтитров на конкретном Android-плеере;
- аппаратное декодирование HEVC/AV1;
- обработку кнопки Back и переключение аудиодорожек.
